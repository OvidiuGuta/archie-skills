# Screenshots

A screenshot needs a home the PR can link:

- **In Archie** — committed under `docs/screenshots/`, as `<task-key>-<slug>.png`, linked by a raw URL pinned to that commit.
- **On files** — committed into the leaf's directory under `.archie/`, as `screenshots/<task-number>-<slug>.png`, linked by a raw URL pinned to that commit.
- **Ad-hoc** — no leaf holds it, so it stays out of the PR.

A screenshot with no file behind it, or none to keep, becomes one line saying what the screen showed.
